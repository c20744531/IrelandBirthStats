Sixty-two years of Irish baby names

I analysed every name given to at least three babies in Ireland since 1964, using open data from the Central Statistics Office, to see how naming has changed: who held the number-one spot, which names are rising and falling, and how Irish spellings are making a comeback.

How I did it

SQL, Python and plain JavaScript
  • Data: CSO tables VSA50 and VSA60 ("Boys/Girls Names in Ireland with 3 or More Occurrences"), pulled from the CSO PxStat API.
  • Cleaning (SQL): loaded about 800,000 raw rows into SQLite, then used SQL to drop the rank rows and blank values, cast the counts and combine boys and girls into one tidy table of year, sex, name and babies.
  • The fada problem (SQL): the data only records fadas from 2018, so every Seán before that is "Sean". I built a SQL view that folds each spelling to an unaccented key, so Rían and Rian count as one name in trends and decade comparisons.
  • Analysis (SQL): window functions (RANK, ROW_NUMBER) for the top 10s and each year's number one, CTEs for 10-year risers and fallers, and aggregates for name diversity, top-10 share and fada share.
  • Pipeline (Python): a short script runs the SQL files in order and exports the results as JSON for the site.
  • Visuals: every chart is hand-built SVG with hover tooltips, no chart library.

Limits of the data

  • Names given to fewer than three babies in a year aren't published, for privacy, so the tables don't add up to total births. The totals also drop sharply between 1997 and 1998, so I don't use them to measure the birth rate.
  • Different spellings are separate names in the official rankings (Fiadh and Fíadh), which can change who's number one.
